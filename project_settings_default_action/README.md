# Project Settings Default Action

Small Odoo 18 addon that changes the main Projects kanban card click behavior.

## Behavior

- Before: clicking a project card opens that project's tasks.
- After: clicking a project card opens the project form/settings page.
- Existing task/stat buttons on the card still keep their explicit actions.

## Install

Copy the `project_settings_default_action` folder into an Odoo addons path, update the app list, then install **Project Settings Default Action**.

If testing in a dev/demo database, restart Odoo after copying the addon if the addons path is cached.
